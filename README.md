# 💪 FIT-AI ChatBot — AI Gym & Fitness Assistant

An AI-powered fitness assistant built with Python and Streamlit that helps users with workouts, nutrition, diet planning, calorie tracking, and fitness guidance.

## ✨ Features

- 🤖 AI Gym Buddy — fitness and workout chatbot
- 🏋️ AI Gym Trainer — live webcam-based exercise tracking
- 🥗 AI Diet Coach — personalized 7-day diet plans
- 🍽️ Meal Analyser — nutrition analysis of meals
- 🛒 Grocery List — generates grocery lists from diet plans
- 📊 Calorie & Macro Tracker — tracks daily calories and macros
- 🔐 Secure API configuration using environment variables
- 🗄️ MongoDB integration for user data
- 📱 Responsive Streamlit interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- MongoDB
- OpenCV
- MediaPipe
- Streamlit WebRTC
- Pandas
